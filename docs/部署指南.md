# 图站生产环境部署指南（1Panel）

> 适用：1Panel（OpenResty + PHP 8.4 + MySQL 8.4 + Redis）生产部署
> 更新日期：2026-08-26

---

## 一、环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| PHP | 8.0+（推荐 8.4） | 需扩展：pdo_mysql、mbstring、curl、openssl、fileinfo、zip、gd、json、dom |
| MySQL | 8.0+ | 生产 8.4 |
| Redis | 任意 | 会话/缓存（当前配置为文件缓存，生产推荐开启） |
| Node.js | 18+ | 仅构建 admin-web 需要（也可本地构建后上传产物） |

> PHP 的 Redis 扩展（`ext-redis`）仅在启用 Redis 缓存时需要，1Panel 应用商店可直接安装。

---

## 二、生产环境配置文件修改清单（★ 核心）

开发环境与生产环境的差异集中在 **1 个环境文件 + 若干配置文件的驱动切换**。按优先级分三类。

### 2.1 必改（不改生产无法正常上线）

#### ① `.env`（项目根目录）

```ini
APP_DEBUG = false          # 生产必须关闭，避免泄露堆栈/路径

DB_TYPE = mysql
DB_HOST = 127.0.0.1        # 1Panel 本机 MySQL 填 127.0.0.1
DB_NAME = picture          # 生产库名
DB_USER = picture          # 生产库账号
DB_PASS = 你的数据库密码
DB_PORT = 3306
DB_CHARSET = utf8mb4

DEFAULT_LANG = zh-cn

STORAGE_DRIVER = r2        # local → r2，切换对象存储

# Cloudflare R2 凭证（STORAGE_DRIVER=r2 时必填）
R2_ACCOUNT_ID = 你的账户ID
R2_ACCESS_KEY = R2 API Token
R2_SECRET_KEY = R2 API Secret
R2_BUCKET = picture
R2_CDN_DOMAIN = https://img.你的域名.com
```

> 改动点：`APP_DEBUG`、`DB_*`、`STORAGE_DRIVER`、`R2_*`。其余不变。

#### ② `admin-web/.env.production`（后台前端构建前新建）

```bash
cd admin-web
echo "VITE_MEDIA_BASE=https://img.你的域名.com" > .env.production
```

> 作用：后台列表里显示的媒体 URL 走 R2 CDN 域名。不配置则图片地址为空/相对路径。

### 2.2 推荐改（性能与生产最佳实践）

#### ③ `config/cache.php` —— 文件缓存 → Redis

```php
return [
    'default' => 'redis',               // 由 file 改为 redis
    'stores'  => [
        'redis' => [
            'type'       => 'redis',
            'host'       => '127.0.0.1',
            'port'       => 6379,
            'password'   => '',          // 1Panel 安装 Redis 时如设了密码则填
            'select'     => 0,
            'timeout'    => 0,
            'expire'     => 0,
            'persistent' => false,
            'prefix'     => '',
            'tag_prefix' => 'tag:',
        ],
    ],
];
```

> 依赖 PHP `ext-redis`。文件缓存在多请求/高并发下性能差，生产建议切 Redis。

#### ④ `config/session.php` —— 会话 → Redis（走 cache 驱动）

```php
return [
    'name'           => 'PHPSESSID',
    'var_session_id' => '',
    'type'           => 'cache',        // 由 file 改为 cache，复用 cache 的 redis 驱动
    'store'          => null,
    'expire'         => 1440,
    'prefix'         => '',
];
```

> 好处：会话不落磁盘、可被多 PHP 进程/多实例共享。

#### ⑤ `config/database.php` —— PDO 持久连接（缓解连接开销）

```php
'connections' => [
    'mysql' => [
        // ...
        'params' => [
            \PDO::ATTR_PERSISTENT => true,   // 复用数据库连接，省去每次握手
        ],
        // ...
    ],
],
```

> 生产 PHP-FPM 下有效：连接按 worker 进程复用，避免每次请求重建连接。

### 2.3 可选改

#### ⑥ `config/log.php` —— 限制日志文件数量

```php
'channels' => [
    'file' => [
        // ...
        'max_files' => 30,   // 默认 0（不清理），建议设上限避免磁盘占满
    ],
],
```

### 2.4 无需修改（已通过 env 驱动 / 已是生产安全值）

| 文件 | 原因 |
|---|---|
| `config/app.php` | `app_map`（admin-api→admin）、`app_express`（前台伪静态）、`show_error_msg=false` 已是生产值，无需改 |
| `config/r2.php` | 全部读 `env('R2_*')`，凭证只填 `.env` |
| `config/storage.php` | `default` 读 `env('STORAGE_DRIVER')` |
| `config/filesystem.php` | 本地磁盘定义，与 R2 切换无关 |

## 三、1Panel 部署步骤（实操）

### 步骤 1：上传代码

1. 将项目源码上传到服务器，例如 `/www/wwwroot/tuzhan`（1Panel 站点默认目录）。
2. 确保 `.env` 已按「2.1 必改」配置好；`.env` 不入 git，生产机需单独创建。

### 步骤 2：创建站点（OpenResty）

1. 1Panel → 网站 → 创建网站 → 运行环境选 **OpenResty**。
2. 运行目录（站点根目录）指向 `项目根/public`。
3. PHP 版本选 **8.4**，伪静态规则选 **ThinkPHP**（或手动填 Nginx 配置，见步骤 6）。
4. 域名填写生产域名，开启 HTTPS（证书自动签发）。

### 步骤 3：创建数据库

1. 1Panel → 数据库 → 创建数据库，库名 `picture` + 账号 `picture` + 强密码。
2. 将连接信息填入 `.env` 的 `DB_*`。

### 步骤 4：安装依赖 + 初始化

```bash
cd /www/wwwroot/tuzhan

# 安装 PHP 依赖（生产不装 dev）
composer install --no-dev --optimize-autoloader

# 执行迁移建表（首次）
php think migrate:run

# 创建管理员账号
php think admin:create --user=admin --password=你的强密码
```

### 步骤 5：构建后台前端

```bash
cd /www/wwwroot/tuzhan/admin-web
npm install
# 已按 2.1② 配置 VITE_MEDIA_BASE
npm run build
```

构建产物输出到 `public/admin/`，由 OpenResty 直接托管静态资源。

> 若服务器不便装 Node，也可在本地 `npm run build` 后把 `public/admin/` 一并上传。

### 步骤 6：Nginx 伪静态（站点配置文件）

```nginx
server {
    listen 80;
    server_name example.com;

    root /www/wwwroot/tuzhan/public;
    index index.php index.html;

    # 后台 Vue SPA：静态资源 + 前端路由回退
    location /admin/ {
        try_files $uri $uri/ /admin/index.html;
    }

    # 后台 API：转发 PHP
    location /admin-api/ {
        index index.php;
        try_files $uri $uri/ /index.php?$query_string;
    }

    # 前台（ThinkPHP 伪静态）
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP 处理
    location ~ \.php(.*)$ {
        fastcgi_pass unix:/tmp/php-cgi-8.4.sock;   # 按 1Panel 实际路径
        fastcgi_index index.php;
        fastcgi_split_path_info ^(.+\.php)(.*)$;
        include fastcgi.conf;
        fastcgi_param PATH_INFO $fastcgi_path_info;
    }
}
```

> HTTPS 证书由 1Panel 自动签发。前端 `/admin/`，接口 `/admin-api/`（已由 `config/app.php` 的 `app_map` 映射到 admin 应用）。

### 步骤 7：定时任务

在 1Panel → 计划任务 添加（每天 03:00 执行 VIP 到期自动降级）：

```cron
0 3 * * * cd /www/wwwroot/tuzhan && /usr/bin/php think vip:expire-check >> /tmp/vip-check.log 2>&1
```

## 四、Cloudflare R2 配置

1. Cloudflare 控制台创建 R2 桶（如 `picture`）。
2. 创建 API Token：权限 `Object Read & Write`，绑定该桶。
3. 桶设置 → 自定义域名，绑定 `img.你的域名.com`（开启橙云代理走 CDN）。
4. `.env` 填入凭证 + `STORAGE_DRIVER=r2` + `R2_CDN_DOMAIN`。
5. 防盗链（Referer 校验）按需开启。

> 本地驱动目录 `public/storage/` 在切换 R2 后不再使用，可忽略。

## 五、上线前检查清单

- [ ] `.env` 生产凭证就位，`APP_DEBUG=false`
- [ ] 数据库迁移已执行，管理员账号已创建且初始密码已修改
- [ ] `STORAGE_DRIVER=r2` + R2 凭证 + CDN 域名生效，图片/视频可正常访问
- [ ] `admin-web` 已用 `VITE_MEDIA_BASE` 构建，后台图片地址正确
- [ ] Redis（如启用）：`config/cache.php` + `config/session.php` 已切换，PHP `ext-redis` 已装
- [ ] Nginx 伪静态 / `/admin` / `/admin-api` 三个入口验证通过
- [ ] HTTPS 证书生效
- [ ] 定时任务 `vip:expire-check` 已配置
- [ ] 内容合规自审；ICP 备案（国内访问）

## 附录：常用命令

| 命令 | 用途 |
|---|---|
| `php think admin:create --user=xx --password=xx` | 创建管理员 |
| `php think migrate:run` | 执行数据库迁移 |
| `php think migrate:rollback` | 回滚迁移 |
| `php think vip:expire-check` | 手动执行 VIP 到期降级 |
| `php think run -H 127.0.0.1 -p 8000` | 本地开发服务器 |
