# 图站部署指南

> 适用：1Panel（OpenResty + PHP 8.4 + MySQL + Redis）生产部署
> 更新日期：2026-08-06

## 一、环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| PHP | 8.0+（推荐 8.4） | 需扩展：pdo_mysql、mbstring、curl、openssl、fileinfo、zip、gd、json、dom |
| MySQL | 8.0+ | 生产 8.4 |
| Redis | 任意 | 会话/缓存（当前配置为文件缓存，可选） |
| Node.js | 18+ | 仅构建 admin-web 需要 |

## 二、初始化流程

```bash
# 1. 安装依赖（Composer 在项目根）
composer install --no-dev --optimize-autoloader

# 2. 配置 .env（数据库 / R2 / 存储驱动）
cp .env.example .env   # 或按下方模板创建

# 3. 创建管理员
php think admin:create --user=admin --password=你的强密码

# 4. 生成测试/运营邀请码（后台「邀请码」页面生成，或命令行）
```

### .env 模板

```ini
APP_DEBUG = false

DB_TYPE = mysql
DB_HOST = 127.0.0.1
DB_NAME = picture
DB_USER = picture
DB_PASS = 你的数据库密码
DB_PORT = 3306
DB_CHARSET = utf8mb4

DEFAULT_LANG = zh-cn

# 存储驱动：local（开发/小站） 或 r2（Cloudflare R2，生产推荐）
STORAGE_DRIVER = r2

# Cloudflare R2 配置
R2_ACCOUNT_ID = 你的账户ID
R2_ACCESS_KEY = R2 API Token
R2_SECRET_KEY = R2 API Secret
R2_BUCKET = picture
R2_CDN_DOMAIN = https://img.你的域名.com
```

> `.env` 已加入 `.gitignore`，不会提交。生产务必设置 `APP_DEBUG=false`。

## 三、后端部署（1Panel）

1. 1Panel 创建站点（OpenResty），运行目录指向 `项目根/public`
2. PHP 版本选择 8.4，开启伪静态（ThinkPHP）
3. 创建 MySQL 数据库 + 账号，填入 `.env`
4. 执行迁移建表（首次）：
   ```bash
   php think migrate:run
   ```
5. 安装 Redis（可选）：修改 `config/cache.php` 与 `config/session.php` 驱动为 redis

## 四、后台前端构建与部署

```bash
cd admin-web
npm install
# 生产 R2 时配置媒体地址：echo "VITE_MEDIA_BASE=https://img.你的域名.com" > .env.production
npm run build
```

构建产物输出到 `public/admin/`（Nginx 托管静态资源）。

> 前端访问 `/admin/`，接口走 `/admin-api/`（已通过 `config/app.php` 的 `app_map` 映射到 admin 应用）。

## 五、Nginx 配置

```nginx
server {
    listen 80;
    server_name example.com;

    root /www/wwwroot/tuzhan/public;
    index index.php index.html;

    # 后台 Vue SPA：静态资源 + 前端路由回退
    location /admin/ {
        try_files $uri $uri/ /admin/index.html;
    }

    # 后台 API：转发 PHP
    location /admin-api/ {
        index index.php;
        try_files $uri $uri/ /index.php?$query_string;
    }

    # 前台（ThinkPHP 伪静态）
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP 处理
    location ~ \.php(.*)$ {
        fastcgi_pass unix:/tmp/php-cgi-8.4.sock;   # 按 1Panel 实际路径
        fastcgi_index index.php;
        fastcgi_split_path_info ^(.+\.php)(.*)$;
        include fastcgi.conf;
        fastcgi_param PATH_INFO $fastcgi_path_info;
    }
}
```

> HTTPS 证书由 1Panel 自动签发。

## 六、Cloudflare R2 配置

1. Cloudflare 控制台创建 R2 桶（如 `picture`）
2. 创建 API Token：权限 `Object Read & Write`，绑桶
3. 桶设置 → 自定义域名，绑定 `img.你的域名.com`（开启橙云代理走 CDN）
4. `.env` 填入凭证 + `STORAGE_DRIVER=r2` + `R2_CDN_DOMAIN`
5. CORS（如需前端直传）：允许 `https://你的域名.com`

**本地驱动目录**：`public/storage/`，生产用 R2 后该目录可忽略。

## 七、定时任务

```cron
# VIP 到期自动降级（每天执行）
0 3 * * * cd /www/wwwroot/tuzhan && /usr/bin/php think vip:expire-check >> /tmp/vip-check.log 2>&1
```

## 八、常用命令

| 命令 | 用途 |
|---|---|
| `php think admin:create --user=xx --password=xx` | 创建管理员 |
| `php think migrate:run` | 执行数据库迁移 |
| `php think migrate:rollback` | 回滚迁移 |
| `php think vip:expire-check` | 手动执行 VIP 到期降级 |
| `php think run -H 127.0.0.1 -p 8000` | 本地开发服务器 |

## 九、后台访问

- 后台地址：`https://你的域名.com/admin/`
- 登录：管理员账号（`php think admin:create` 创建）
- 后台功能：仪表盘、内容管理（图集/单图/视频 + 上传）、分类标签、卡密批次/卡密、VIP 发放、邀请码、用户、评论审核、系统设置

## 十、备份策略

- **MySQL**：1Panel 定时备份数据库
- **图片/视频**：R2 自带对象版本管理，无需额外备份
- 本地驱动模式：备份 `public/storage/` 目录
